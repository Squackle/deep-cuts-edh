# Hive Run Release Naming

**Permanent rule:** Every Hive Run release/update title must be **exactly one thematic, evocative word** related to the hive, mutations, underground world, or its creatures. Do not use explanatory or informational phrases as titles.

Display the semantic version number separately as metadata (e.g. version 1.0.5, title **Instinct**), not inside the one-word title. Technical details go below the title.

Apply this to release notes, update announcements, patch notes, roadmap milestones, the public-game badge, and Development Lab patches. Preserve this convention in future handoffs and new sessions.

Current release: **Instinct** (version 1.0.5).
