What this report does—and does not—prove

This page analyzes the current 500 puzzle definitions. It does not run the expensive winning-route check in your browser. The repository's offline audit command verifies legal reference replays, and its test checks run in CI. Even successful legal replays do not establish globally optimal routes, strategy uniqueness, beginner comprehension, accessibility, or a public release license.
